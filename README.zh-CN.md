# Token 悬浮球

[English](README.md) · 简体中文

一个 macOS 桌面小工具，查看 Codex、Claude Code 和 Google Antigravity 的输出速度和每日、历史 Token 用量。

- 在悬浮球、菜单栏或两处同时显示总速率。展开后可看各来源和对话的速率。
- 查看今日累计和历史用量。活动图支持每日、每周、累计，以及按来源切换。
- 在「设置 → 常规」选择展开面板里要显示的来源。收起后仍能看所有启用来源的合计。点击面板外可收起。
- 设置中可调整数据来源、开机启动、猫咪动画和累计用量的数字格式。
- 在「设置 → 关于」点击「检测更新」，或通过 GitHub 查看正式发布。

## 下载

从 [GitHub Releases](https://github.com/sixiaohanle/token-float/releases/latest) 下载 ZIP，解压后将 `Token 悬浮球.app` 移到「应用程序」。

发布包适用于 Apple 芯片和 macOS 13 或更新版本。发布包使用临时签名，首次打开时 macOS 可能阻止运行。也可以按下文在本机从源码构建，构建脚本会使用当前 Mac 的架构。

## 从源码构建

准备 macOS 13 或更新版本，以及支持 Swift 5.9 或更新版本的 Xcode 命令行工具。在仓库根目录运行：

```sh
./work/build-token-float.sh
```

生成的应用位于 `outputs/Token 悬浮球.app`。

## 数据与更新

Antigravity App 和 IDE 每写完一段模型输出，悬浮球就用该段的输出 token 数除以实际生成秒数，更新 T/s。默认读取 `~/.gemini/antigravity/conversations` 和 `~/.gemini/antigravity-ide/conversations` 里的本地数据库。缺少计时记录的旧会话无法测速。

每日和历史用量来自本机的会话记录。Antigravity 统计已记录的输入、缓存读取、缓存写入和输出 token，同一会话在 App 和 IDE 中的副本只计一次。只有旧版 `.pb` 文件的会话缺少可读取的用量。首次使用会在后台补录可读取的历史用量，之后持续将每日总量保存到本机。已保存的用量在原日志删除后仍可查看，新用量继续累加。设置中的「数据来源」可指定自定义目录，或重新扫描新增日志。Codex 的 `.zst` 归档需要本机可用的 `zstd` 才能导入。

对话列表显示实时输出速率，历史统计按日期和来源汇总。应用的用量数据库保存每日汇总和用于去重的匿名标识。应用启动时及运行期间会向 GitHub 查询正式版本，检查请求无需登录。

归档补录能确认日期的计入当天，只能确认月份的计入对应月份。Codex 本机状态库里缺原日志的归档累计直接计入总量，累计值可能含有分支继承用量。账本已有原日志记录的归档会跳过。恢复原日志后，应用会用对应日志用量替换已补录的累计值。
